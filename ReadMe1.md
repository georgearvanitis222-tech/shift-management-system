# Σύστημα Διαχείρισης Βαρδιών Εργαζομένων Βιομηχανικής Μονάδας

## Περιγραφή Έργου

Η παρούσα εφαρμογή αναπτύχθηκε στο πλαίσιο του εργαστηριακού μαθήματος **«Τεχνολογίες Διαδικτύου στην Ψηφιακή Βιομηχανία»** του Πανεπιστημίου Δυτικής Αττικής.

Η εφαρμογή προσομοιώνει ένα πραγματικό βιομηχανικό περιβάλλον στο οποίο απαιτείται η διαχείριση εργαζομένων και των βαρδιών τους. Μέσω της διαδικτυακής εφαρμογής ο διαχειριστής μπορεί να καταχωρεί εργαζομένους, να αναθέτει βάρδιες, να προβάλλει το πρόγραμμα εργασίας και να διαχειρίζεται τα δεδομένα του προσωπικού.

Σκοπός του έργου είναι η κατανόηση της ανάπτυξης διαδικτυακών εφαρμογών με χρήση Web Server και Βάσης Δεδομένων, καθώς και η εφαρμογή των γνώσεων σε ένα σενάριο σχετικό με την Ψηφιακή Βιομηχανία.

---

# Στόχοι της Εφαρμογής

Οι βασικοί στόχοι της εφαρμογής είναι:

* Η ανάπτυξη διαδικτυακής εφαρμογής με χρήση PHP.
* Η σύνδεση εφαρμογής με βάση δεδομένων MySQL.
* Η εισαγωγή, αποθήκευση και ανάκτηση δεδομένων.
* Η διαχείριση βαρδιών εργαζομένων.
* Η δημιουργία φιλικού περιβάλλοντος χρήστη.
* Η αξιοποίηση τεχνολογιών διαδικτύου σε βιομηχανικό σενάριο.

# Δομή Βάσης Δεδομένων

## Πίνακας Employees

Ο πίνακας αποθηκεύει τα στοιχεία των εργαζομένων.

| Πεδίο      | Περιγραφή                 |
| ---------- | ------------------------- |
| id         | Κωδικός εργαζομένου       |
| name       | Ονοματεπώνυμο εργαζομένου |
| department | Τμήμα εργασίας            |

---

## Πίνακας Shifts

Ο πίνακας αποθηκεύει τις βάρδιες των εργαζομένων.

| Πεδίο       | Περιγραφή           |
| ----------- | ------------------- |
| id          | Κωδικός βάρδιας     |
| employee_id | Κωδικός εργαζομένου |
| shift_date  | Ημερομηνία βάρδιας  |
| shift_type  | Τύπος βάρδιας       |

---

## Σχέση Πινάκων

Κάθε εργαζόμενος μπορεί να έχει πολλές βάρδιες.

Η σύνδεση μεταξύ των δύο πινάκων πραγματοποιείται μέσω του πεδίου:

```text
employee_id
```

το οποίο συνδέεται με το πεδίο:

```text
id
```

του πίνακα εργαζομένων.

# Λειτουργίες της Εφαρμογής

## 1. Σύνδεση Διαχειριστή

Η εφαρμογή διαθέτει μηχανισμό πιστοποίησης χρήστη (Login).

Ο διαχειριστής εισάγει:

* Όνομα χρήστη
* Κωδικό πρόσβασης

και αποκτά πρόσβαση στις λειτουργίες διαχείρισης του συστήματος.

---

## 2. Dashboard

Η αρχική σελίδα του συστήματος παρουσιάζει:

* Τον συνολικό αριθμό εργαζομένων.
* Τον συνολικό αριθμό βαρδιών.
* Μενού πρόσβασης σε όλες τις λειτουργίες.

---

## 3. Προσθήκη Εργαζομένου

Η λειτουργία επιτρέπει:

* Καταχώρηση νέου εργαζομένου.
* Καταχώρηση τμήματος εργασίας.

Τα δεδομένα αποθηκεύονται στη βάση δεδομένων.

---

## 4. Ανάθεση Βάρδιας

Ο διαχειριστής μπορεί να:

* Επιλέξει εργαζόμενο.
* Επιλέξει ημερομηνία.
* Επιλέξει τύπο βάρδιας.

Οι διαθέσιμοι τύποι βαρδιών είναι:

* Πρωινή
* Απογευματινή
* Νυχτερινή

---

## 5. Προβολή Προγράμματος Βαρδιών

Η εφαρμογή εμφανίζει:

* Κωδικό βάρδιας
* Όνομα εργαζομένου
* Τμήμα
* Ημερομηνία βάρδιας
* Τύπο βάρδιας

Τα δεδομένα ανακτώνται μέσω SQL ερωτημάτων και σύνδεσης των πινάκων της βάσης δεδομένων.

---

## 6. Διαχείριση Εργαζομένων

Η λειτουργία επιτρέπει:

* Προβολή όλων των εργαζομένων.
* Διαγραφή εργαζομένων.
* Αυτόματη διαγραφή των αντίστοιχων βαρδιών τους.
